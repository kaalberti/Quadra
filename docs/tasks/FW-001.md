# FW-001 — individual-servo bench controller

Completed2026-10-08. Actual target build passes for ESP32-S3-DevKitC-1-N8:
19,288bytes RAM,295,605bytes flash. No upload or hardware test.
`firmware/test.ps1` passes12 independent scenarios against the same C++ code.
Tests cover command parsing, disable-before-enable ordering, channel selection,
pulse bounds/quantization, timeout across millis wrap, bus failure, startup
failure, disarm-before-bus-write, latched faults and PCA register behavior.

Initialization was corrected during review to avoid clearing full-off through
ALL_LED broadcast writes. Per-channel full-off is retained. Configuration is
read back at initialization, before moves/keepalives and every100ms while armed.
Oscillator timing and physical GPIO/output behavior still need measurement.

Build dependencies are repository-local copies of existing PlatformIO packages.
Host compiler is checksum-verified official portable Zig0.13.0; no global install.
The external servo power cutoff remains necessary even when PWM is disabled.
