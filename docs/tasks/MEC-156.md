# MEC-156 — removable chassis attachment

Working sources: prototype-chassis-mount.scad and prototype-chassis-assembly.scad.
Exports: left/right mount STLs, matching drilled deck STL and assembly preview.
Existing leg CAD and MFG-002 are preserved. Two mounts of each hand attach four
legs; bracket thickness7mm, flange6mm, deck4mm. Exported mount66 x59 x33mm;
deck180 x110 x4mm, inside a conservative300mm bed envelope.

The mount replaces the7mm bench adapter at the existing four cradle/support
slots, reusing four M3 x20 fasteners per leg. Four new M3 x16 fasteners per
flange add16 bolts/16 nuts/32 washers to the robot BOM. No bracket purchases,
board replacement, battery or full-robot print release are introduced.

`node mechanical/check-chassis-mount.mjs` passes on actual exported meshes:
closed edge ownership, one connected surface, bed origin, bounding dimensions,
equal mirrored volume and unobstructed fixing rays at centre and3mm envelope.
Solid PETG estimates31.52g/mount and99.81g deck, not measured print mass.
